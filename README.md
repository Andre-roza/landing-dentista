# Lumina Odontologia Premium - Landing Page v2.0

Landing Page de alta conversão para clínica odontológica premium. Design moderno, responsivo, com foco em conversão, desenvolvido utilizando HTML5 e Tailwind CSS (via CDN).

## 🚀 Tecnologias Utilizadas

- **HTML5** (Semântico)
- **Tailwind CSS** (Estilização via CDN oficial)
- **Alpine.js** / Vanilla JS (Interações básicas e animações)
- **Google Fonts** (Fontes elegantes importadas diretamente)

## ⚙️ Como Executar Localmente

Como o projeto é estático (HTML puro), você não precisa rodar builds ou instalar dependências de pacotes.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
3. Se desejar rodar em um servidor local para desenvolvimento rápido, você pode usar a extensão **Live Server** no VS Code ou rodar usando Python/Node:
   ```bash
   # Com Python 3
   python -m http.server 8000
   
   # Com Node (npx)
   npx serve .
   ```
